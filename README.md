# Serio Website (Sonic Lab)

A modern, high-performance website for Serio, featuring the Sonic Lab branding and the Reference Tool Guide.

## 🚀 How to Run on Another Computer

If you want to work on this project on a different machine, follow these steps:

### 1. Prerequisites
- **Node.js**: Download and install from [nodejs.org](https://nodejs.org/).
- **Git**: Download and install from [git-scm.com](https://git-scm.com/).

### 2. Clone the Repository
Open your terminal (Command Prompt, PowerShell, or Terminal) and run:
```bash
git clone https://github.com/spaolos88-cloud/serio-website.git
cd serio-website
```

### 3. Install Dependencies
Download all the necessary libraries:
```bash
npm install
```

### 4. Start the Development Server
Run the website locally:
```bash
npm run dev
```

The terminal will show a URL (usually `http://localhost:5173`). Open that in your browser to see the site!
